# Prompts (withheld)

The real persona and caller prompts used in the private repo are **withheld from this public mirror for
safety**: the caller prompt in particular is a persuasive scam script, and publishing it would give
copy-paste material to real fraudsters. `kamla.md` and `scammer.md` here are minimal neutral placeholders
so the code path loads. Safety in this project comes from code (filters, verifier, draft-only reports),
not from prompts.
