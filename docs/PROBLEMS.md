# Problems we faced

Format: problem, what we did, result. Sources: an internal document (not shipped), `deploy/DEPLOY.md`, `docs/security/gate-check-2026-11-22.md`, git history.

| # | Problem | What we did | Result |
|---|---|---|---|
| 1 | **Lyzr latency above budget.** Our first budget was 1.8 s per turn. Measured p95 was 2.9-3.7 s. | Checked models. No model fixed it, since the delay is Lyzr-side overhead. Raised the budget to 3.5 s (`lyzr_turn_budget_s`) and added a filler line that plays during the wait. Added a latency HUD to the dashboard. | Accepted risk, written down. The pause is covered, not removed. The offline 1.7 s figure is the stub's simulated delay and is not quoted as real. |
| 2 | **AdaL token confusion.** The token we first pasted was a browser session JWT that expired in 60 s. | Stopped using the pasted token and moved to the AdaL CLI app path. | AdaL runs live. |
| 3 | **AdaL account had 0 credits.** | Founder approved about $10 of credits (bought directly). | 3 paid calls used so far. |
| 4 | **AdaL stream-json output was not parsed.** The answer arrives as a `{"type":"answer"}` event. | Fixed `parse_adal_output` (`app/agents/reporter.py`). Tests went 131 to 135. | Narrative of 4-6 sentences in about 23 s. |
| 5 | **AdaL could do too much.** A coding agent with tools could read files or reach the network. | Disabled tools, ran it in an empty temp directory with a minimal environment, and forced its traffic through a CONNECT proxy that allows one host (gate G3). Refused to run when no host is set. | No identifiers leaked in the live narrative. |
| 6 | **Finch returned 0 results for fraud keywords.** | Retargeted the keywords (for example "scam" returns 13 skills), tried them in order inside a 4 s budget, and added a dated real snapshot as fallback. | Live scout works. Role stays discovery only. |
| 7 | **Hosted image could not play cached audio.** With no Kokoro engine, the TTS adapter returned a stub even when the clip was on disk. | Made `_synth_kokoro` check the cache first (commit `8990e6f`). | Hosted image plays the 112 pre-rendered clips. New text gets no audio there. |
| 8 | **Band keys.** Per-agent keys and the room id had to be provisioned. Band demo agents worked on app.band.ai before the app had keys. | Verified the agents on app.band.ai. Built the mirror so events say `mirrored:true/false` honestly, with an in-process fallback. | Keys provisioned; see #12 for the live post. |
| 9 | **Voice input waiver not approved.** | Treated a blank waiver as not approved. Built typed push-to-talk with a notice. | Input is typed. The video says so. |

| 11 | **Detector scored 31% on real transcripts.** | Added a redacted real-world sandbox (Docker `--network none`, data gitignored) and fixed the rules. | Progression 31% (real transcripts) to 86% to 95% scam-type, alert recall 64% to 91%. Caveats: press paraphrases, not ASR speech; same news-heavy register as v2; wide intervals; single labeller; the advisory guard could miss a scammer reciting "never share your OTP". v3 is consumed, further tuning needs v4. |
